# OpenRig Studio
### Open-Source 2D Character Animation & Rigging Engine

OpenRig Studio is a next-generation animation platform inspired by professional animation software such as Moho Pro. It aims to bring character rigging, skeletal animation, motion editing, physics simulation, drawing tools, and 2D/3D workflows into one unified creative environment.

The project is designed for animators, developers, indie creators, and technical artists who want a flexible, extensible animation toolkit.

## ✨ Features

### 🎭 Character Rigging & Animation
- Bone-based character rigging and skeleton mapping
- Inverse Kinematics (IK) for natural character movement
- Keyframe animation and timeline editing
- Motion paths and trajectory editing
- Onion skinning for frame-by-frame animation
- Multi-character animation and independent joystick controls
- Reusable character rigs and animation presets

### 🎨 Drawing & Asset Studio
- Canvas-based drawing and layered editing
- Layer connections, masking, and transformations
- Character, clothing, props, and environment asset libraries
- Custom asset creation and reusable components
- SVG import, layer manipulation, and 3D extrusion

### 🎥 Camera & Scene Controls
- Camera navigation and orbit controls
- Multi-angle character and environment editing
- Scene composition and depth management
- Lighting, shadows, and 2D depth effects

### ⚙️ Physics & Simulation
- Jiggle and secondary-motion physics
- Cloth and accessory movement
- Physics-driven character effects
- Configurable animation constraints
- 2D-to-3D visual effects and shading

### 🧩 Developer-Friendly Architecture
- Modular animation systems
- Reusable rigging and rendering components
- Extensible tools and asset pipelines
- Potential plugin and automation support
- Designed for future AI-assisted animation workflows

## 🎯 Project Goals

- Build an accessible and extensible animation engine.
- Simplify complex character rigging and animation workflows.
- Combine drawing, animation, physics, and scene editing in one workspace.
- Enable developers to create custom animation tools and integrations.
- Explore new approaches to interactive and AI-assisted animation.

## 🏗️ Architecture

The planned architecture is organized into modular systems:

- **Editor UI:** Workspace, panels, canvas, and tool controls.
- **Animation Engine:** Timeline, keyframes, interpolation, and motion paths.
- **Rigging Engine:** Skeletons, bone mapping, IK, and constraints.
- **Rendering Engine:** Canvas rendering, layers, masks, lighting, and depth.
- **Physics Engine:** Secondary motion, jiggle physics, and simulation.
- **Asset Manager:** Characters, clothing, props, rigs, and reusable assets.
- **Scene & Camera System:** Scene hierarchy, camera navigation, and composition.

## 🚀 Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
cd OpenRig-Studio
```

Install dependencies using the package manager configured by your project.

For a Node.js project using npm:

```bash
npm install
npm run dev
```

> These commands are a starting point for a compatible Node.js setup. Update them to match the actual project structure and scripts in `package.json`.
